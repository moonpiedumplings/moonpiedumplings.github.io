# If you are newbie, read this

## ~~Use this it's better~~

If you try do literally anything, someone will explain to you that there is a better way to do it. They are probably even right.

But, if you constantly switch the technology stack, you will never get anything done. 


"What's the difference between good code and bad code? Bad code ships."


Here is a version of this argument

## ~~Learn X before Y~~

I hear this one a lot. In some cases, I disagree, and some concept or technology actually does have prerequisites. But, running head first into those things was a valuable learning experience for me, even if I failed. I think it's unfair for those of us to deny people lessons the other 

But, I also disagree. I think there are a lot of times where you don't actually need to learn X before learning Y, especially in regards to "lower level" software. I find that trend especially frustrating
